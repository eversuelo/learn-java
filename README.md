# Learn Java

This repository contains a structured path to learn the Java programming language, from the fundamentals to more advanced topics.

## Repository Structure

### [01-fundamentals/](./01-fundamentals)
Core language concepts:
- Variables and primitive data types.
- Type conversion.
- Console input with `Scanner`.
- Number systems.

### [02-control-flow/](./02-control-flow)
Decision-making structures:
- Conditionals (`if`, `else`, `switch`).
- Comparison and logic operators.

### [03-loops/](./03-loops)
Repetition structures:
- `for`
- `while`
- `do-while`
- `for-each`

### [oop/](./oop)
Object-oriented programming fundamentals:
- Creating classes and objects.
- Attributes and methods.
- Examples with `Vehicle` and `Employee`.

### [04-data-structures/](./04-data-structures)
Basic and abstract data structures:
- **ArrayProblems**: array exercises.
- **LinkedListCollection**: linked lists.
- **QueueCollection**: queues.
- **StackCollection**: stacks.
- **TreeCollections**: trees.

### [05-algorithms/](./05-algorithms)
Algorithms and analysis:
- **complexity-analysis**: introduction to time complexity (Big O).

## How to Use This Repository

Each folder is organized to suggest a learning order. You can navigate into each folder and run the `.java` files directly:

```bash
javac FileName.java
java FileName
```
