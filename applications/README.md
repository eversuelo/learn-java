# Applications

This folder is reserved for larger, practical Java exercises.
After learning syntax and isolated examples, you need small applications that combine multiple concepts.

## What Should Live Here

Good application ideas:
- Console calculator
- Student grade manager
- Inventory tracker
- Simple banking simulator
- Task manager
- Text-based menu application

## Skills Combined in This Section

Applications should force you to combine:
- Variables and types
- Conditions
- Loops
- Arrays or collections
- Methods
- Classes and objects
- Input/output
- Exception handling

## Why This Folder Matters

A learner often understands isolated syntax but struggles to connect it into a full program.
This section closes that gap.

## Suggested Progression

1. Build one console app with only variables, `if`, and loops.
2. Refactor it using methods.
3. Refactor it again using classes.
4. Add validation and exception handling.
5. Replace arrays with collections where appropriate.
