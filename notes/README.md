# Notes

This folder is the learning log. One file per algorithm, data structure, or concept.

## What Goes Here

The log is **not** a summary of the lecture or the book. Summaries are worthless later, because
the source material is still there and better written than your summary.

What belongs here is the part you cannot look up:

- What you got wrong on the first attempt, and why.
- The off-by-one that cost you an hour.
- The sentence, drawing, or example that finally made it click.
- The question you could not answer yet.

If a note contains nothing that surprised you, it is not worth writing.

## How to Use It

1. Copy `_TEMPLATE.md` to a new file when you start a topic.
2. Name it `NN-topic.md` in the order you studied it, for example `03-merge-sort.md`.
3. Fill in the *before* sections when you start and the *after* sections when you finish.
4. Never delete a wrong first guess. Strike it through and write the correction next to it. The
   contrast is the most valuable thing in the file.

## Naming

```
notes/
  01-asymptotic-notation.md
  02-insertion-sort.md
  03-merge-sort.md
  04-quicksort.md
  ...
```

## Review Cadence

- **Same day:** finish the note while the confusion is still fresh.
- **One week later:** re-read the note and try to re-implement the algorithm from a blank file.
  Record whether you succeeded. If you did not, the note was incomplete - fix it.
- **Before each new phase:** skim every note from the previous phase.
