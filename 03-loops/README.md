# 03 Loops

This module introduces the main loop structures in Java.

## Topics

- `for`: useful when the number of iterations is known.
- `while`: useful when a condition controls repetition.
- `do-while`: executes the block at least once before checking the condition.
- `for-each`: useful for iterating over arrays and collections.

- `WhileLoop.java`
- `DoWhileLoop.java`
